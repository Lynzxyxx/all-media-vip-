📸 Instagram Downloader

Tempel link Instagram (post, reel, story, atau IGTV), lalu kamu akan diarahkan ke halaman download di fastdl.app.

Fitur ini memakai fastdl.app (bukan API JSON terbuka, karena fastdl.app tidak menyediakan itu secara gratis — akses API resmi mereka harus lewat kontak/berbayar). Sebagai gantinya dipakai cara resmi yang mereka dokumentasikan sendiri: link Instagram-mu ditempel ke belakang f-d.app/, lalu kamu diarahkan ke halaman hasil download mereka di tab baru. Gunakan hanya untuk konten publik dan hormati hak cipta pembuatnya.

📌 Pinterest Downloader

Tempel link pin Pinterest (pin.it atau pinterest.com/pin/...). Sistem otomatis mencoba beberapa sumber kalau salah satu limit/gagal.

⬇️ Buka/Download Media
Tidak ada API Pinterest gratis tanpa-key yang setara tikwm (TikTok), jadi fitur ini mencoba bertahap: 1) endpoint widget resmi Pinterest (jika pin punya data publik & ID numerik) — hasil tampil langsung di sini kalau berhasil. Kalau gagal/terbatas, 2) otomatis membuka SavePin.app di tab baru dengan link pin-mu sudah terisi. Kalau SavePin.app juga sedang limit, coba cadangan manual: SavePin.onl. Gunakan hanya untuk konten publik dan hormati hak cipta pembuatnya.

🔗 Tourl — Ubah Foto Jadi Link

Upload gambar, dapatkan link langsung yang bisa dibagikan ke mana saja. Gratis, tanpa perlu daftar akun.

📤

Klik untuk pilih gambar (JPG, PNG, GIF, WEBP)

Buka Link ↗
Fitur ini otomatis mencoba beberapa layanan hosting gambar gratis secara berurutan (Catbox → 0x0.st → tmpfiles.org → file.io) — kalau satu sedang limit/gagal, otomatis lanjut coba yang berikutnya tanpa perlu API key atau daftar akun. Link yang dihasilkan bersifat publik (siapa pun yang punya link bisa melihat gambarnya), dan durasi penyimpanan bisa beda-beda tergantung layanan mana yang berhasil (Catbox & 0x0.st permanen, tmpfiles.org & file.io ada batas waktu/beberapa minggu). Jangan upload foto pribadi/sensitif yang tidak ingin dilihat orang lain.

🎬 Tourl Video — Ubah Video Jadi Link

Upload video, dapatkan link langsung yang bisa dibagikan ke mana saja. Gratis, tanpa perlu daftar akun.

📤

Klik untuk pilih video (MP4, MOV, WEBM, dll)

Buka Link ↗
Sama seperti Tourl foto, fitur ini otomatis mencoba beberapa layanan hosting file gratis secara berurutan (Catbox → 0x0.st → tmpfiles.org → file.io) — kalau satu sedang limit/gagal, otomatis lanjut ke yang berikutnya. Video berukuran besar mungkin butuh waktu upload lebih lama tergantung koneksi internet. Link bersifat publik — jangan upload video pribadi/sensitif.
